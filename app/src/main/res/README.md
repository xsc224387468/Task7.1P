## How to Run

1. **Import the Project**  
   Open the `Task71P` folder in Android Studio.

2. **Build and Run**  
   Connect an emulator or a real device, then click the "Run" button to build and launch the app.

3. **Try the Features**
    - On the main screen, click "CREATE A NEW ADVERT" to post a new advert.
    - Click "SHOW ALL LOST & FOUND ITEMS" to view all adverts.
    - Click any advert in the list to view details and remove it if needed.

4. **Note**
    - If you change the database structure, please uninstall the app and reinstall it to ensure the table structure is updated.
